# 🧬 In-Silico Molecule Profiler & 3D Visualizer

A Python-based computational chemistry script built with **RDKit** and **py3Dmol**. It analyzes small molecules via SMILES strings, computes key physicochemical properties (Lipinski's Rule of 5), calculates partial Gasteiger charges, and renders interactive 3D visualizations.

---

## ✨ Features
* 📏 **Physicochemical Properties Calculation**: Molecular Weight, LogP, H-Bond Donors/Acceptors, Rotatable Bonds, and TPSA.
* 💊 **Drug-likeness Screening**: Automated verification against **Lipinski's Rule of 5**.
* ⚡ **Gasteiger Partial Charges**: Computes partial charge distribution (Max Positive & Max Negative).
* 🔮 **Interactive 3D Visualization**: Renders 3D molecular structures with optional toggleable charge overlays using `py3Dmol`.

---

## 🛠️ Tech Stack
* **Python 3**
* **RDKit** (Cheminformatics & Descriptors)
* **py3Dmol** (3D Rendering)
